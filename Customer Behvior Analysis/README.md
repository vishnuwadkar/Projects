# Customer Shopping Behavior Analysis

A data analytics project focused on understanding customer purchasing patterns, product preferences, revenue drivers, and segmentation in a retail environment. The project combines Python-based data preparation with SQL analysis to answer real business questions and support decision-making.

## Overview

This project explores a synthetic customer shopping dataset to uncover patterns such as:

- revenue contribution by gender and age group
- the effect of discounts on spend
- top-rated and frequently purchased products
- customer segmentation (new, returning, loyal)
- comparison of subscriber vs non-subscriber spending
- shipping and payment behavior trends

The analysis is implemented in a Jupyter notebook and supported by a set of SQL queries for business analysis.

## Project Goals

- Clean and validate the retail dataset
- Engineer useful features for behavioral analysis
- Identify key customer segments and spending trends
- Answer business questions with SQL and data analysis
- Prepare raw customer insights suitable for reporting and dashboarding

## Dataset

The project uses the file `customer_shopping_behavior.csv`.

This dataset contains information about customers, products, purchasing behavior, demographics, and transaction characteristics, including:

- Customer ID
- Age and gender
- Product and category purchased
- Purchase amount in USD
- Location and size preferences
- Color, season, and review rating
- Subscription status and previous purchases
- Payment method, shipping type, and discount usage
- Frequency of purchases

## Project Structure

- `Customer_Shopping_Analysis.ipynb` – Python notebook for data cleaning, feature engineering, and exploratory analysis
- `business_analysis.sql` – SQL queries answering business and marketing questions
- `customer_shopping_behavior.csv` – source dataset
- `Customer Behavior Analysis.pbix` – Power BI dashboard/report file
- `Customer Shopping Behavior Analysis - Project Report.pdf` – summary project report

## Analysis Workflow

1. Load the raw CSV file into a pandas DataFrame.
2. Inspect structure, summary statistics, and missing values.
3. Impute missing review ratings using category-based median values.
4. Standardize column names and clean the dataset.
5. Create derived attributes such as age groups and purchase frequency days.
6. Remove redundant fields and load the cleaned data into PostgreSQL.
7. Run SQL queries to answer key business questions.

## Key Questions Answered

The project analyzes questions such as:

- What is the total revenue generated by male vs female customers?
- Which customers used a discount but still spent above the average amount?
- What are the top five products by average review rating?
- How do standard and express shipping compare in average purchase value?
- Do subscribed customers spend more than non-subscribers?
- Which products have the highest discount adoption rate?
- How many customers fall into new, returning, and loyal segments?
- Which products dominate each category by purchase count?
- Are repeat buyers more likely to subscribe?
- What is the revenue contribution of each age group?

## Setup

### Prerequisites

- Python 3.9+
- Jupyter Notebook or VS Code with Python support
- PostgreSQL running locally
- Optional: Power BI Desktop for viewing the `.pbix` dashboard

### Install dependencies

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary
```

### Run the notebook

Open `Customer_Shopping_Analysis.ipynb` in Jupyter or VS Code and execute the cells in order.

### Database loading

The notebook includes code to create a local PostgreSQL database and insert the cleaned DataFrame into a table. Ensure PostgreSQL is installed and running before executing that section.
